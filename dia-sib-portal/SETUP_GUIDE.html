Overview

How the Portal Works

The portal is a lightweight local web application. When you ask a question, it searches the team's Confluence space, retrieves the most relevant pages, sends them as context to Claude (via the Siemens SDC LLM Gateway), and streams the answer back to your browser — in real time.

Nothing is sent to the public internet. Both the LLM Gateway (llm.sdc.siemens.cloud) and Confluence (wiki.si.siemens.cloud) are internal Siemens infrastructure.

🔒
Security note

Each team member uses their own personal Confluence API token. No shared credentials. The server only reads Confluence — it never creates or modifies pages unless explicitly asked.

Setup Steps

Step-by-Step Installation

1

Get the Portal Files

You need two files: app.py (the server) and this guide. Request them from your team lead or download from the shared team location.

Option A — Copy from a colleague's machine
Copy the dia-sib-portal folder to your machine. Place it anywhere convenient, for example:

target folder
C:\Projects\dia-sib-portal\
target folder
~/Projects/dia-sib-portal/

Option B — Create the folder manually
Create a new folder named dia-sib-portal and place app.py inside it.

After this step, your folder should look like this:

📁 dia-sib-portal/ ├── app.py ← the server (required) ├── .env ← you will create this in Step 5 └── SETUP_GUIDE.html ← this file
⚠️
Do not share the .env file

The .env file contains your personal API tokens. Each person creates their own. Never commit it to git or send it via email.

2

Verify Python is Installed

Open a terminal and run:

powershell 
python --version
terminal 
python3 --version

You should see something like Python 3.11.4. Any version 3.10 or newer works.

⚠️
Python not found?
  • On Windows: try py --version or python3 --version
  • If none work, contact your IT team to install Python, or download it from python.org/downloads
  • During installation, tick "Add Python to PATH"

Note down the exact command that works for you (python, python3, or py). You will use it in the next steps.

3

Install Required Packages

Open a terminal, navigate to the dia-sib-portal folder, and run the install command:

powershell 
# Navigate to the folder first
cd C:\Projects\dia-sib-portal

# Install all required packages
pip install fastapi uvicorn httpx python-multipart
terminal 
# Navigate to the folder first
cd ~/Projects/dia-sib-portal

# Install all required packages
pip3 install fastapi uvicorn httpx python-multipart

This will download and install 4 small packages. It takes about 30–60 seconds. You should see Successfully installed ... at the end.

PackageWhat it does
fastapiThe web framework that powers the server
uvicornRuns the FastAPI server
httpxMakes HTTP requests to Confluence and Claude
python-multipartHandles form data from the browser
ℹ️
Corporate proxy issues?

If pip fails with a connection error, your corporate proxy may be blocking it. Try:

powershell
pip install fastapi uvicorn httpx python-multipart --trusted-host pypi.org --trusted-host files.pythonhosted.org
4

Get Your Personal Confluence API Token

The portal reads Confluence pages on your behalf. For this, it needs a personal API token — think of it as a password specifically for API access. This is not your Siemens password.

Follow these steps in your browser:

  1. Log in to Confluence: https://wiki.si.siemens.cloud
  2. Click your profile picture (top right corner)
  3. Select "Profile" from the dropdown menu
  4. In your profile page, click "Personal Access Tokens" in the left sidebar
    (If you don't see it, try: Profile → Settings → Personal Access Tokens)
  5. Click "Create token"
  6. Fill in:
    • Token name: DIA SI B Portal (or any name you prefer)
    • Expiry: Set to 1 year, or leave as default
  7. Click "Create"
  8. Copy the token immediately — it is only shown once
⚠️
Save the token now — you cannot see it again

Once you close the token creation screen, Confluence will not show the token value again. If you lose it, you need to create a new one. Copy it to a temporary notepad before the next step.

✅
No special permissions needed

The token inherits your normal Confluence permissions. If you can read pages in the SIDCRSS space through the browser, the token can read them too.

5

Create Your .env Configuration File

The portal reads its configuration from a file called .env inside the dia-sib-portal folder. This file stores your personal tokens — it stays on your machine and is never shared.

Create the file using any text editor (Notepad, VS Code, etc.)

Create a new file named exactly .env (with a dot at the start, no extension) in the dia-sib-portal folder, with the following content:

.env (your configuration file) 
# Confluence connection
CONF_BASE_URL=https://wiki.si.siemens.cloud
CONF_TOKEN=PASTE_YOUR_CONFLUENCE_TOKEN_HERE

# Siemens SDC LLM Gateway (Claude)
# Ask your team lead for this key
ANTHROPIC_API_KEY=PASTE_YOUR_SDC_API_KEY_HERE
ANTHROPIC_BASE_URL=https://llm.sdc.siemens.cloud

Replace PASTE_YOUR_CONFLUENCE_TOKEN_HERE with the token from Step 4, and PASTE_YOUR_SDC_API_KEY_HERE with the key provided by your team lead.

ℹ️
Creating a file that starts with a dot on Windows
  • Open Notepad, paste the content, then go to File → Save As
  • In the filename box, type .env (with the dot)
  • Change "Save as type" to All Files (*.*)
  • Navigate to the dia-sib-portal folder and click Save

Your folder should now look like this:

📁 dia-sib-portal/ ├── app.py ├── .env ← just created ✓ └── SETUP_GUIDE.html
6

Start the Server

Open a terminal, navigate to the dia-sib-portal folder, and run:

powershell / cmd 
cd C:\Projects\dia-sib-portal
python -m uvicorn app:app --host 0.0.0.0 --port 8000
terminal 
cd ~/Projects/dia-sib-portal
python3 -m uvicorn app:app --host 0.0.0.0 --port 8000

You should see output like this — which means the server is running:

expected output
INFO:     Started server process [12345]
INFO:     Waiting for application startup.
INFO:     Application startup complete.
INFO:     Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)
⚠️
Keep this terminal window open

The server runs as long as this terminal window stays open. If you close it, the portal stops. To stop the server intentionally, press Ctrl + C in the terminal.

💡
Tip: run in background (optional)

If you want the server to keep running after closing the terminal, on Windows you can use:

powershell
Start-Process python -ArgumentList "-m uvicorn app:app --host 0.0.0.0 --port 8000" -WorkingDirectory "C:\Projects\dia-sib-portal" -WindowStyle Hidden
7

Open the Portal in Your Browser

With the server running, open your browser and go to:

browser address bar 
http://localhost:8000

You should see the DIA SI B Knowledge Base portal with a search box and suggested questions. Try clicking one of the suggestion chips or typing your own question.

🎉
You're set up!

If you see the portal and can ask a question that returns an answer with sources from Confluence — everything is working correctly.

Team collaboration

Sharing the Portal with the Team

There are three ways to share the portal, depending on your situation:

Option A — Everyone runs their own local copy (simplest)

The simplest approach. Each team member installs the portal on their own machine following this guide. The portal runs on localhost:8000 — only they can access it.

What to share with each person:

  • app.py — the server file
  • SETUP_GUIDE.html — this guide
  • The SDC API key (provided by team lead via secure channel)

What each person creates themselves:

  • Their own .env file with their own Confluence token

Pros: No shared server to maintain. Each person controls their own setup. Works offline (on local network).

Cons: Everyone needs to install Python and packages. Each person needs their own Confluence token.

Option B — One shared server on a team machine or VM

One person installs and runs the server on a machine accessible to the whole team (e.g., a shared Windows VM, a team server). Everyone connects to that one URL instead of running it locally.

Setup on the shared machine: Follow Steps 1–6 of this guide on the shared machine. Then team members open the portal at:

browser
http://<shared-machine-ip-or-hostname>:8000

Find the shared machine's IP on Windows:

powershell
ipconfig | findstr "IPv4"

Example: if the result is 192.168.1.45, team members go to http://192.168.1.45:8000.

Important: Both machines must be on the same network (or VPN). The server machine's firewall must allow inbound connections on port 8000.

Pros: Team members only need a browser — no Python installation required.

Cons: The shared machine must stay on. The Confluence token in .env is shared (one account reads on behalf of everyone).

Option C — Deploy to an internal server for permanent access (advanced)

For a permanent, always-on solution accessible from any device on the Siemens network, deploy the portal to a Siemens-approved server or Azure App Service (internal).

This option requires IT involvement and is beyond the scope of this guide. The application itself is ready — it only needs a host. Contact your IT team with these details:

  • Runtime: Python 3.10+
  • Command: python -m uvicorn app:app --host 0.0.0.0 --port 8000
  • Environment variables: 4 variables as documented above
  • Outbound access needed: wiki.si.siemens.cloud and llm.sdc.siemens.cloud (both internal)
  • No database, no file storage, no external dependencies

Troubleshooting & FAQ

The server starts but the answer says "No relevant pages found in Confluence"

This means the portal connected to the server, but the Confluence search returned no results. Possible causes:

  • Wrong or expired Confluence token — Open your .env file and check that CONF_TOKEN has the correct value. If unsure, regenerate it in Confluence (Step 4) and update the file, then restart the server.
  • Not on the Siemens network — You must be on the Siemens VPN or internal network to reach wiki.si.siemens.cloud.
  • The topic isn't documented in Confluence — Try a different, broader question. Not all topics may be documented yet.
  • CONF_BASE_URL is wrong — It must be exactly https://wiki.si.siemens.cloud with no trailing slash.
I get "Address already in use" when starting the server

Another process is already using port 8000. Options:

  • Find and stop the other process that's using port 8000, or
  • Run the portal on a different port by adding --port 8001 (or any other free port) to the start command, then open http://localhost:8001

On Windows, to find what's using port 8000:

powershell
netstat -ano | findstr :8000
I get "ModuleNotFoundError: No module named 'fastapi'" (or similar)

The packages were installed for a different Python version than the one running the server. Make sure you use the same python command to both install packages and start the server.

For example, if you installed with python3 -m pip install ..., start the server with python3 -m uvicorn ....

Alternatively, install packages explicitly for the Python you will use:

terminal
python -m pip install fastapi uvicorn httpx python-multipart
pip install fails with a connection error or SSL error

Your corporate proxy is likely blocking pip. Try:

terminal
pip install fastapi uvicorn httpx python-multipart --trusted-host pypi.org --trusted-host files.pythonhosted.org

If that still fails, ask your IT team for the proxy configuration, or request them to install the packages for you.

The portal loads but Claude's answer is an error or empty

The issue is likely with the SDC API key. Check that:

  • ANTHROPIC_API_KEY in your .env has the correct value (no extra spaces or line breaks)
  • ANTHROPIC_BASE_URL is exactly https://llm.sdc.siemens.cloud
  • You are connected to the Siemens network or VPN

Ask your team lead to confirm you have the correct API key.

How do I stop the server?

In the terminal where the server is running, press Ctrl + C. The server will stop immediately.

Can I use the portal on my phone or tablet?

Yes, if you are using Option B (shared server). Connect your phone/tablet to the same network and open http://<server-ip>:8000 in the browser. The interface is responsive and works on mobile.

For Option A (local), the portal only runs on your own machine.

My Confluence token expired — how do I renew it?
  1. Log in to https://wiki.si.siemens.cloud
  2. Go to your Profile → Personal Access Tokens
  3. Create a new token (you can delete the old one)
  4. Update the CONF_TOKEN value in your .env file
  5. Restart the server (Ctrl+C, then run the start command again)
Can I ask questions about topics outside of Confluence?

The portal is designed to answer questions grounded in the team's Confluence documentation. If a topic isn't documented there, the portal will tell you it couldn't find relevant information and suggest alternative places to look (e.g., JIRA, team contacts).

It will not make up answers — all responses are based on content found in Confluence.

Is my data private? What gets sent where?

Here is exactly what leaves your machine when you ask a question:

  • To wiki.si.siemens.cloud — a search query (the keywords from your question) and a request to read specific pages. This is the same as searching Confluence normally.
  • To llm.sdc.siemens.cloud — your question and the text of the Confluence pages retrieved. This goes to the Siemens-internal SDC LLM Gateway, not to any public Anthropic servers.

Nothing is sent to the public internet. Both endpoints are internal Siemens infrastructure subject to Siemens data governance policies.

How do I keep the portal always running on startup (Windows)?

You can add the server as a Windows startup task. The simplest way is to create a batch file and add it to the Windows startup folder:

1. Create a file named start-portal.bat in the dia-sib-portal folder:

start-portal.bat
@echo off
cd /d C:\Projects\dia-sib-portal
python -m uvicorn app:app --host 0.0.0.0 --port 8000

2. Press Win + R, type shell:startup, press Enter

3. Place a shortcut to start-portal.bat in that folder

The server will start automatically when Windows starts.
